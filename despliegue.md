# Instrucciones de despliegue

## Proyecto

GymTracker - Proyecto Final DAW

---

## Backend

Entrar en la carpeta del backend:

```bash
cd gymtracker-backend
```

Ejecutar Spring Boot:

```bash
mvnw.cmd spring-boot:run
```

---

## Frontend

Entrar en la carpeta frontend:

```bash
cd gymtracker-frontend
```

Abrir el archivo:

```bash
index.html
```

Cambio en master
